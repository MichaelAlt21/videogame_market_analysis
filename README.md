# Анализ рынка видеоигр

Исследовательский анализ заведений исторических данных развития игровой индустрии для написания статьи-исследования посредством ознакомления, предобработки и анализа данных за определенный период.

## Цель проекта

Основные задачи проекта:
- Загрузить и ознакомиться с данными;
- Исследовать названия столбцов датафрейма, типы данных, наличие пропусков, дубликаты;
- Отобрать данные по времени выхода игры, категоризовать игры по оценкам, выделить топ платформ по количеству игр;
- Сделать вывод;

## Данные

В датасете содержится информация о:
- название игры.
- название платформы.
- год выпуска игры.
- жанр игры.
- продажи в Северной Америке (в миллионах проданных копий).
- продажи в Европе (в миллионах проданных копий).
- продажи в Японии (в миллионах проданных копий).
- продажи в других странах (в миллионах проданных копий).
- оценка критиков (от 0 до 100).
- оценка пользователей (от 0 до 10).
- рейтинг организации ESRB (англ. Entertainment Software Rating Board). Эта ассоциация определяет рейтинг компьютерных игр и присваивает им подходящую возрастную категорию.

## Используемые технологии

Python, pandas, Jupyter Notebook.

## Этапы работы

1. Загрузка данных и знакомство с ними.
2. Проверка ошибок и предобработка данных.
3. Фильтрация данных.
4. Категоризация данных.
5. Анализ данных и выводы.

## Основные результаты

- Преобразованы типы данных: Год релиза с float64 на int64, JP sales, EU sales и User Score с object на float64. Замена пропусков: пропуски в EU sales и JP sales заменены на среднее по группам, в оценках и рейтинге на индикаторы-заглушки ("-1" и "unknown"), записи с пропусками в Name, Year of Release, Platform, Genre удалены. Устранение дубликатов: явные дубликаты удалены, неявные приведены к общему виду. Текстовые данные, кроме рейтинга, нормализованы, приведены к виду нижнего регистра, пробелы удалены (не у названий).
- Кол-во обнаруженных и исправленных пропусков: 25142 (277 записей с крит. пропусками удалены); Кол-во дубликатов: 236 записей удалено + 13 уникальных значений исправлено; Название одного рейтинга исправлено.
- Отобраны данные за 2000-2013 года включительно.
- Данные категоризованы по оценкам пользователей так: высокая оценка (от 8 до 10 включительно), средняя оценка (от 3 до 8, не включая правую границу интервала) и низкая оценка (от 0 до 3, не включая правую границу интервала). По оценкам критиков так: высокая оценка (от 80 до 100 включительно), средняя оценка (от 30 до 80, не включая правую границу интервала) и низкая оценка (от 0 до 30, не включая правую границу интервала).
- Получился следующий топ-7 платформ: ps2 - 2127 игр, ds - 2120 игр, wii - 1275 игр, psp - 1180 игр, x360 - 1121 игр, ps3 - 1086 игр, gba - 811 игр.
